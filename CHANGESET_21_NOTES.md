# Change set 21 — automatic mining with D69

Branch: `slug-automatic-miner`, stacked on set 20 implementation `ca3c069e`.

## What changed

Mike approved D69: broadcast block wins immediately and allow the exact
canonical winning block to qualify within its original five-minute job.
The decision and rationale are recorded in `BRAWLCHAIN_SPEC.md` and
`ADR_003_AUTOMATIC_MINING.md`.

Explicit registry schema 4 atomically stores admission-time eligibility with
the existing job, proof, gym authorization and birth. Service/client protocol
v2 selects the new guard and strictly validates receipts. `slugregistry
init-mining` initializes a separate store; daemon ready output identifies the
configured protocol. The node verifies original-parent and winner membership,
raw header equality and chain identity without a redundant authority hash.
Block submission reports uncertain outcomes separately from explicit rejection.

The automatic worker constructs payable candidates, scans production PoW,
renews jobs, broadcasts wins before automatic signing and retains a synchronized
public outbox for exact retries. Separate block/prospect delivery state survives
restart; retained capacity and future receipt reservations bound storage.
See `PROSPECT_WORKER.md` for lifecycle and integration boundaries.

## Deliberately unchanged

Consensus, genesis, production PoW parameters, checkpoint report-only policy,
the seed's persistent data and private RPC are unchanged. Service v1/schema 3
retain their current-parent rule. D68 issuance-based birth and final expiry
remain unchanged; old registries are never migrated implicitly. No real key,
wallet, account or payout is provisioned. Hosted wallet/login and tested full
export remain desktop/account integration work under D48. No public authority
or miner starts on the seed with this release.
