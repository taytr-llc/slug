## Change and reason

The original 32-by-32 name pool repeats heavily at larger populations. This set
adds a separately reviewed 512-by-512 candidate, preserving existing names and
all original v1 bytes. The new manifest and renderer are explicitly version2;
DNA, non-name traits, portrait graphics and the fight-engine algorithm are
unchanged. Different manifest inputs can legitimately change downstream
commitments and RNG inputs; no equal-outcome claim is made across substitutions.

The exact descriptor is
`cd02ae57b5918548244be2cabbe6c0c433feb5a1c165745e2e5c6bf235128e75`.
All old defaults remain v1. Additive runtime and launch options require explicit
v2 selection with an absolute data root. Outer account, inner runtime and issuer
source mismatches refuse before locks or journal mutation. Established roots
never choose their own authority from disk, repin history or silently migrate.

Source-bound dispatch now covers admission, worker delivery, stable/entry/event
transport, card/bout reconstruction, native portraits and frontend validation.
It retains the original complete source equality at each authority boundary.
The shared practice route remains disabled; existing solo practice stays v1.
No navigation, layout, logos, real accounts or production activation changed.
See `NAME_DIVERSITY.md` and the complete frozen independent reference bundle at
`fighterdescriptor/testdata/name-v2`.

## Independent expectations and collision evidence

Root reviewed the complete name lists and byte contracts before reference
generation. Exact tables, archived v1 inputs, contract hashes, scripts and public
sample inputs were frozen first. The preserved Python implementation generates
expectations independently of Go, including complete canonical manifest and SVG
bytes, both digests and the full descriptor. It was regenerated from the archived
repository location with no outside files required. Go output never replaced an
expected vector.

The reference contains 764 complete cases covering all 512 first names and 512
surnames, actual apostrophes, wrong tuples, 24 stream byte vectors, counter
boundaries and unchanged v1/non-name graphics. The original v1 corpora remain
byte-identical. One old API negative test now asks for unknown version3 because
version2 is deliberately supported; no frozen v1 expected output changed.

The fixed 100,000-seed public experiment produces 82,987 distinct v2 names and
31,969 fighters with namesakes, versus 1,024 distinct v1 names and 100,000 with
namesakes. At 10,000, v2 has 399 fighters with namesakes. The complete Go generator
matches the independent observed counts, all six population scenarios and seed
stream digest. The separate uniform model is a scenario model, not a mining
distribution claim, population forecast or release threshold. D51 still allows
duplicates; presentation and remaining ambiguity go to the final D74 review.
